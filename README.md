# PortfolioHUB

Portfólio profissional desenvolvido com React e TailwindCSS para organização de projetos acadêmicos e pessoais.

## Tecnologias Utilizadas

- React
- TailwindCSS
- JavaScript
- Vite
- Git
- GitHub

## Estrutura do Repositório

```bash
PortfolioHUB/
│
├── projetos-academicos/
├── projetos-pessoais/
├── documentacao/
├── assets/
├── src/
└── README.md
```

## Objetivo

Este repositório foi criado para aplicar conceitos de versionamento com Git, hospedagem no GitHub e desenvolvimento web moderno.

## Projetos Acadêmicos

- Sistema Locadora
- Banco de Dados
- Engenharia de Software

## Funcionalidades

- Organização de projetos
- Portfólio responsivo
- Versionamento com Git
- Publicação com GitHub Pages
